================================================================================
DESIGN SYSTEM REFERENCE
Margin/Padding Rules, Colors, Typography, Animations
================================================================================
Single source of truth for design tokens. Theme variables and base styles live
in src/global.css (Tailwind v4 @theme + :root / .dark). Project/works layout
patterns live in src/styles/works.module.css.

QUICK REFERENCE
--------------------------------------------------------------------------------
Standard spacing scale: 0.25rem, 0.5rem, 1rem, 1.25rem, 2.5rem, 5rem
Mobile breakpoint: 935px
Border radius: 8px (media), 30px (tags)
Max widths: 720px (images), 960px (YouTube), 1440px (grids)
Fonts: General Sans (body), Boska (display/titles), Poppins, Tanker (accents)

BREAKPOINTS
--------------------------------------------------------------------------------
Mobile Breakpoint: 935px
  - Used in media queries: @media (max-width: 935px)
  - Tailwind @theme: --breakpoint-mobile: 935px (src/global.css)

================================================================================
ANIMATIONS
================================================================================
Defined in src/global.css.

Fade-in:
  .fade-in — opacity 0 → 1, transform; transition 0.8s ease-out
  Toggle via data-visible="true"

Keyframes:
  fadeIn — opacity 0 → 1
  swipeIn — from translateX(100%), opacity 0 → translateX(0), opacity 1; 0.4s ease-in-out
  swipeInFromLeft — from translateX(-100%), opacity 0 → translateX(0), opacity 1; 0.4s ease-in-out

Utility classes:
  .swipe-left / .swipe-right — transform + opacity 0
  .swipe-in / .swipe-in-from-left — animation applied

Page transitions (App.jsx): AnimatePresence opacity 0 → 1, duration 0.3, easeInOut


================================================================================
NOTES
================================================================================

- All spacing values use rem units (relative to root font-size of 16px)
- Mobile breakpoint is consistently 935px across the codebase
- Padding patterns typically reduce on mobile (e.g., 5rem → 2.125rem or 3rem)
- Color system uses CSS variables for theme switching (global.css :root / .dark)
- Hover states consistently use rgb(140, 140, 140) for text color changes
- Description images have max-width: 720px; max-height: 480px
- Description videos have max-height: 480px
- Progress videos have max-height: 815px
- Project vertical videos have max-width: 720px; max-height: 1280px
- Large images use max-width: 1200px (via .largeImage class)
