BREAKPOINTS
--------------------------------------------------------------------------------
Mobile Breakpoint: 935px
  - Used in media queries: @media (max-width: 935px)
  - Tailwind config: --breakpoint-mobile: 935px


================================================================================
COLOR SYSTEM
================================================================================

CSS VARIABLES (Theme-based)
--------------------------------------------------------------------------------

LIGHT THEME (:root)
  --color-background: white
  --color-text: black
  --color-border-gray: #bdbdbd
  --color-keyword-text: rgb(113, 113, 113)
  --color-keyword-bg: #ececec
  --color-text-muted: rgb(194, 194, 194)
  --color-figcaption: black

DARK THEME (.dark)
  --color-background: black
  --color-text: white
  --color-border-gray: #bdbdbd (same as light)
  --color-keyword-text: #ececec
  --color-keyword-bg: rgb(113, 113, 113)
  --color-text-muted: rgb(194, 194, 194) (same as light)
  --color-figcaption: white

ADDITIONAL COLORS (Used in Components)
--------------------------------------------------------------------------------
Hover States:
  - rgb(140, 140, 140) - Used for hover text color on links/buttons
  - rgb(118, 118, 118) - Footer text (dark theme)
  - rgb(170, 170, 170) - Footer text (light theme)

Background Colors:
  - #111111 - Footer background (dark theme)
  - #f0f0f0 - Footer background (light theme)
  - white - Default background
  - black - Default dark background

Border Colors:
  - #bdbdbd - Standard border gray (used in hr elements)


================================================================================
SPACING SYSTEM (Margin & Padding)
================================================================================

COMMON PADDING VALUES
--------------------------------------------------------------------------------

Small Spacing:
  0.25rem  (4px)   - Small padding (e.g., keyword tags, mobile iframe)
  0.5rem   (8px)   - Small padding (e.g., progress video)
  0.625rem (10px)  - Small margin/padding (e.g., hr margin, progress grid gap)

Medium Spacing:
  0.75rem  (12px)  - Keyword gap
  1rem     (16px)  - Standard small spacing
  1.25rem  (20px)  - Common padding/margin (hr margin, description padding)
  2rem     (32px)  - Medium spacing
  2.5rem   (40px)  - Common section padding (project info, descriptions)

Large Spacing:
  3rem     (48px)  - Large padding (mobile project info, description sections)
  3.75rem  (60px)  - Large padding (project info bottom, progress title mobile)
  4rem     (64px)  - Extra large padding (project info top, credits, references)
  5rem     (80px)  - Extra large padding (description, credits sections)
  6rem     (96px)  - Very large (mobile project main margin-top)
  8rem     (128px) - Extra large (project basics padding-right)
  10rem    (160px) - Extra large (project info horizontal padding)

================================================================================
NOTES
================================================================================

- All spacing values use rem units (relative to root font-size of 16px)
- Mobile breakpoint is consistently 935px across the codebase
- Padding patterns typically reduce on mobile (e.g., 5rem → 3rem)
- Color system uses CSS variables for theme switching
- Hover states consistently use rgb(140, 140, 140) for text color changes
