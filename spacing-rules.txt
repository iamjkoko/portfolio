============================================================
6) RECOMMENDED NORMALIZED SCALE
============================================================
Proposed spacing tokens (rem):
- 0.125rem
- 0.25rem
- 0.5rem
- 0.75rem
- 1rem
- 1.25rem
- 2rem
- 2.5rem
- 3rem
- 4rem
- 5rem
- 8rem
- 10rem

Rationale
- Keeps existing visual rhythm while removing uncommon increments.
- Preserves all major section sizes already used in layout.
- Reduces one-off values that make spacing harder to maintain.

Unit policy
- Layout spacing (margin/padding/gap): use rem tokens.
- Keep px only where tied to typography/icon optical alignment.
- Keep em only when intentionally tied to font size behavior.

============================================================
7) VALUE NORMALIZATION MAP
============================================================
Replace uncommon spacing values:
- 0.625rem -> 0.75rem (or 0.5rem where tighter spacing is desired)
- 2.125rem -> 2rem
- 3.125rem -> 3rem
- 3.75rem -> 4rem

Optional unit harmonization:
- 60px -> 3.75rem (or 4rem to align with token scale)
- 12px -> 0.75rem
- 0.05em -> keep (micro inline icon offset, font-relative)
